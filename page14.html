AWS Solution Architect – Practice Test (Page 14)

Question 121 – Topic 1 (Verbatim)

Question:
A financial company is planning to migrate its web application from on premises to AWS. The company uses a third-party security tool to monitor the inbound traffic to the application. The company has used the security tool for the last 15 years, and the tool has no cloud solutions available from its vendor.
The company plans to deploy the application on Amazon EC2 instances that run in an Auto Scaling group in a dedicated VPC.
The company needs to use the security tool to inspect all packets that come in and out of the VPC. This inspection must occur in real time and must not affect the application’s performance.
A solutions architect must design a target architecture on AWS that is highly available within an AWS Region.

Which combination of steps should the solutions architect take to meet these requirements? (Choose two.)

Options (Verbatim)
✅ Correct Answers: A and D
🧠 Trainer-Level Explanation

This is a classic “third-party network appliance” question. AWS is testing whether you recognize the one AWS service built specifically for inline packet inspection.

🔑 Step 1: Identify the non-negotiable requirements

Third-party security tool
No cloud-native version
Inspect all packets (L3/L4)
Must not affect application performance

🔑 Step 2: Recognize the Gateway Load Balancer (EXAM GOLD)

Gateway Load Balancer (GWLB) is designed for firewalls/IDS/IPS and third-party security appliances. It preserves IPs, offers near-zero latency, and scales appliances.

✅ Option A: Deploy the security tool on EC2 instances in ASG — required because vendor provides EC2 appliance
✅ Option D: Provision a GWLB per AZ — required to transparently steer traffic to appliances with high availability and performance

❌ B, C, E are incorrect for reasons explained above. 
Question 122 – Topic 1 (Verbatim)

Question:
A company has purchased appliances from different vendors. The appliances all have IoT sensors. The sensors send status information in the vendors' proprietary formats to a legacy application that parses the information into JSON. The parsing is simple, but each vendor has a unique format.
Once daily, the application parses all the JSON records and stores the records in a relational database for analysis.
The company needs to design a new data analysis solution that can deliver faster results and optimize costs.

Which solution will meet these requirements?

Options (Verbatim)
✅ Correct Answer: A
🧠 Trainer-Level Explanation

Use IoT Core → Lambda → S3 → Glue → Athena/QuickSight for near-real-time, serverless, cost-effective analytics. This eliminates daily batch and RDBMS costs. 
Question 123 – Topic 1 (Verbatim)

Question:
A company is migrating some of its applications to AWS. The company wants to migrate and modernize the applications quickly after it finalizes networking and security strategies.
The company has set up an AWS Direct Connect connection in a central network account. The company expects to have hundreds of AWS accounts and VPCs in the near future.
The corporate network must be able to access the resources on AWS seamlessly and also must be able to communicate with all the VPCs. The company also wants to route its cloud resources to the internet through its on-premises data center.

Which combination of steps will meet these requirements? (Choose three.)

Options (Verbatim)
✅ Correct Answers: B, D, F
🧠 Trainer-Level Explanation

Use a central DXGW + TGW (transit VIF), share TGW across accounts, and route egress via on-prem NAT — hub-and-spoke hybrid architecture that scales. 
Question 124 – Topic 1 (Verbatim)

Question:
A company uses AWS Organizations with all features enabled. The company wants to centralize the purchase of Reserved Instances (RIs) so that only the organization’s management account can purchase RIs.
The company wants to prevent member accounts from purchasing Reserved Instances while still allowing them to use the RI discounts that are shared across the organization.

Which solution will meet these requirements?

Options (Verbatim)
✅ Correct Answer: C
🧠 Trainer-Level Explanation

Use an SCP denying the purchase API in member accounts while exempting the management account; RI sharing still works.
